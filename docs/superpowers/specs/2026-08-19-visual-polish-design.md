# 视觉打磨：Hero 场景升级 + 全站广播层 + 完成度修复

日期：2026-08-19
状态：已与作者对齐（方案 A+B+修 bug；C 只做便宜项）
背景：站点交互仪式感强（CLI 开机 → 3D 电视 → 滚动推进 → NO SIGNAL 换台），但穿过开场后正文视觉密度低，"空白读起来像没做完而不是留白"。本轮只做视觉与动效，**所有文案维持现状当占位符**，内容结构（案例页、时间线）不在本轮范围。

诊断依据：19 张全站 headless 截图（桌面 1440×900 + 移动 390×844，日/夜、各 section、子页、聚焦态）。

---

## A · Hero 3D 场景升级

涉及：`src/three/tv.ts`、`src/three/stage.ts`、`src/three/screen.ts`

### A1 电视主体

- **占比加大**：相机起点 `startPos` 拉近，并/或电视整体 scale 提高，目标是电视在 1440×900 首屏画面中的视觉宽度提升约 15–25%（现状约 20% 屏宽，偏小）。`endPos`/`endLook` 与 `labelAnchor`、`knobWorld` 等锚点随之校准。
- **建模细节**（保持程序化建模、无外部资产）：
  - V 形天线：两根细圆柱 + 底座半球，位于机顶后部。
  - 双旋钮：现有旋钮旁增加第二颗（音量），主旋钮周围加刻度环（环形排列的短刻度块）。
  - 木纹侧板：CanvasTexture 程序化生成木纹（噪声条纹 + 轻微色差），贴机身两侧。
  - 机身倒角：外壳盒体改为带倒角的近似（分段盒或 Shape+extrude bevel），消除锐利棱线。
- 现有元素保留：扬声器格栅、脚垫、电源线、屏幕。

### A2 柜面道具

低多边形、同色系（跟随日/夜主题色变化），摆在电视两侧不抢主体：

- 叠放录像带 3–4 盘（薄盒 + 浅色标签面，微错位旋转）。
- 遥控器（小圆角盒 + 按钮点阵）。
- 小盆栽（花盆圆台 + 2–3 层锥形叶簇）。
- 墙面挂画/挂钟为**可选项**，默认不做（防杂乱）。

### A3 光影

- **日间**（治"白天太素"）：
  - 暖色窗光 SpotLight，`spotlight.map` 用 canvas 画窗格图案，投斜方形窗光斑到墙面与柜面；`castShadow` 开。
  - 电视落在柜面的软阴影加强（shadow radius / 强度调参）。
- **夜间**：
  - 屏幕辉光 PointLight（teal 色调），强度随屏幕内容做轻微 flicker（低频噪声，幅度小，reduced-motion 时静止）。
  - spot 光锥内加尘埃粒子（THREE.Points，数量少、缓慢漂浮，仅夜间可见；reduced-motion 时不动）。
- **柜面微反射**：倒置镜像的 TV 网格 + 自上而下透明度渐变，做假反射（不做真实时反射）。
- 日/夜切换时新增光源与道具颜色全部纳入现有 `setTheme` 的 GSAP 过渡。

### A4 屏幕内容（dolly 终点不再空）

- `screen.ts` 增加**测试卡模式**：滚动进度 p 超过阈值（约 0.65，实现时调参）后，屏幕内容淡切为经典电视测试卡——同心校准圆 + 色条 + 网格 + `CH 00` 字样 + cry 像素 logo。雪花转场前的特写一瞬有完整画面可看。
- 平时待机画面底部加**节目条跑马灯**：`正在播出：作品集 · CH 00` 循环滚动，丰富屏幕层次。
- 频道编号统一约定：电视屏幕 = 开机频道 `CH 00`，正文各区 = `CH 01–05`（见 B1）；现有待机画面角标里的 `CH 03` 一并改为 `CH 00`。
- 屏幕纹理仍为 CanvasTexture 实时绘制，测试卡为绘制函数分支，不引入图片资产。

## B · 全站"广播层"装饰系统

涉及：`index.html`、`src/styles/main.css`、`src/gallery.ts`、`src/about.ts`、少量新 fx 代码

### B1 频道角标（统一语言）

每个 section 固定位置（左上或右上）出现 mono 角标，格式统一：

| 区域 | 角标 |
|---|---|
| #about | `CH 01 · 关于` |
| #works | `CH 02 · 精选作品` |
| #manifesto | `CH 03 · 宣言` |
| #footer | `CH 04 · 联系` |
| 子页 #page-about | `CH 05 · 关于 cry` |

进入 section 时角标做一次短暂"跳台"闪烁（CSS animation；reduced-motion 时直接显示）。此编号体系为将来"案例频道页"铺概念，本轮纯视觉。

### B2 频段刻度尺

视口右缘固定竖向刻度尺（细 tick marks + 每 section 一个粗刻度），滚动时高亮当前频段位置，与 B1 角标联动（少量 JS 读 ScrollTrigger 进度）。移动端隐藏。

### B3 扫描线底纹

`#content` 背景在现有网格上叠加极淡横向扫描线（CSS repeating-linear-gradient，透明度 ≤3%），压暗大面积空黑的"未完成感"。

### B4 海报重绘 ×3

数据结构不变（`content.ts` 不动），只改 `gallery.ts decor()` 与对应 CSS：

- **血与火（fire）**：细线 `🜂` 三角 → 像素三头龙徽记（CSS grid 像素画）+ 底部火焰上升渐变；保持红黑基调。
- **浴血黑帮（peaky）**：黑上黑 → 牛皮纸档案质感：米色纸卡底、红线串联的空照片框 2–3 个、加大并旋转的"机密"章、订书钉/回形针细节。未聚焦变暗后仍需轮廓可辨。
- **拼豆（beads）**：off 珠透明度大幅降低（近不可见），爱心珠加径向高光成珠子质感，让爱心剪影立起来。

### B5 子页蓝图重画

`#blueprint` SVG 从"方框+十字"重画为 **CRT 电视解剖线稿**：机身正面轮廓、屏幕圆角矩形、显像管侧视锥体、天线、2–3 条标注引线与尺寸标注。沿用现有 `pathLength=100` + 滚动 stroke 绘制机制；四角"能力 #1–4"标签的引线指向电视对应部位。文案不动。

### B6 空白支撑元素

- #about 右下：信号强度条纹样（阶梯 bars）+ 频率读数装饰字。
- #manifesto 背景：超大号 `CH 03` 极淡水印（在 echo 层之下）。
- 子页 hero：现有轴线加坐标刻度与光标读数装饰字。
- #footer：只加 B1 角标，保持克制。

## D · 完成度修复（全修）

1. **子页蓝链接**：胶囊按钮样式从 `#cta`（ID 选择器）迁移到 `.pill` 类级，子页「联系我」恢复胶囊外观；`#cta` 保留布局差异部分。
2. **「交汇点」断词**：`.type-title` 加 `word-break: keep-all; line-break: strict`，打字机标题在词组边界断行（必要时在 `content.ts` 文案里用不可断标记/手动断点，仍算视觉修复不算改文案）。
3. **works intro 与 HUD 重叠**：#works 头部布局让位（intro 下移/加顶距），滚动过程中不再与固定 HUD 文字叠字。
4. **CRY logo 日间对比度**：日间 `--hud` 色加深或 logo 点阵加不透明度，顶部中央 logo 清晰可见。
5. **NO SIGNAL 后台冻结**：`nosignal.ts` 监听 `visibilitychange`，页面恢复可见时若转场仍在播且已超时则立即完成并清屏，杜绝黑屏残留盖页。

## 验收

- `npm run build`（tsc + vite）通过。
- headless 截图脚本同机位前后对比：日间 hero 不再"下半屏空白 + 小电视"；dolly 终点为测试卡；三张海报重绘生效；子页蓝图为电视解剖线稿；子页「联系我」为胶囊按钮。
- 日/夜切换过渡平滑，新增光源/道具颜色随主题。
- `prefers-reduced-motion` 下：新增动效全部静止或直显，无功能缺失。
- WebGL 不可用降级路径不回归（stage try/catch 分支仍工作）。
- 移动端（390 宽）各 section 无布局破损，B2 刻度尺隐藏。
